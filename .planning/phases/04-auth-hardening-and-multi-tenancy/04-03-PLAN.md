  <action>
    **CRITICAL SAFETY RULE:** Every queryset in a controller method that accesses a resource MUST chain `.filter(organization=request.organization)` BEFORE `.aget()`. Never look up by ID globally then check membership after — that leaks timing information. Cross-org lookups must return 403 Forbidden per user decision (explicit denial, standard B2B SaaS pattern).

    1. **django_matt/multitenancy/controllers.py**: Full async rewrite of all 4 controllers (19 methods total). For each method:
       - Change `def method(self, request)` to `async def method(self, request)`
       - Replace ALL sync ORM calls:
         - `.get()` -> `.aget()`
         - `.filter().first()` -> `.filter().afirst()`
         - `.filter().exists()` -> `.filter().aexists()`
         - `.save()` -> `.asave()`
         - `.delete()` -> `.adelete()`
         - `.create()` -> `.acreate()`
         - `list(queryset)` -> `[obj async for obj in queryset]`
         - `.count()` -> `.acount()`
         - `.values_list()` -> async iteration
       - Ensure all resource lookups chain `organization=request.organization` and return 403 for cross-org:
         ```python
         # CORRECT (org-scoped query + 403 for cross-org per user decision):
         team = await Team.objects.filter(organization=request.organization, id=id).afirst()
         if not team:
             return JsonResponse({"detail": "Forbidden"}, status=403)

         # WRONG (global lookup then check — leaks timing, still wrong pattern):
         team = await Team.objects.aget(id=id)
         if team.organization != request.organization:
             return JsonResponse({"detail": "Forbidden"}, status=403)
         ```
         Note: Both the "not found in scope" and "exists but wrong org" cases return 403 — this is the explicit denial pattern chosen by the user. The org-scoped filter is still preferred because it avoids the global lookup and potential timing leak.
       - For `OrganizationController`: list should return only orgs where user has membership (via Membership filter). Create should auto-add creator as owner.
       - For `TeamController`: all queries scoped to `request.organization`.
       - For `MembershipController`: all queries scoped to `request.organization`.
       - For `InvitationController`: all queries scoped to `request.organization`.
       - Use `orjson.loads(request.body)` for body parsing (matching AuthController pattern).
       - Use the org-aware permission classes from Plan 02 where appropriate (e.g., `permission_classes = [IsAuthenticated, IsOrgMember]` on controller class).

    2. **django_matt/multitenancy/decorators.py**: Add async detection to all 7 decorators. Follow the pattern from `auth/decorators/jwt.py`:
       ```python
       import inspect
       from functools import wraps

       def requires_organization(func):
           if inspect.iscoroutinefunction(func):
               @wraps(func)
               async def async_wrapper(self_or_request, *args, **kwargs):
                   request = _get_request(self_or_request, args, kwargs)
                   if not getattr(request, "organization", None):
                       return JsonResponse({"detail": "Organization context required"}, status=400)
                   return await func(self_or_request, *args, **kwargs)
               return async_wrapper
           else:
               @wraps(func)
               def sync_wrapper(self_or_request, *args, **kwargs):
                   request = _get_request(self_or_request, args, kwargs)
                   if not getattr(request, "organization", None):
                       return JsonResponse({"detail": "Organization context required"}, status=400)
                   return func(self_or_request, *args, **kwargs)
               return sync_wrapper
       ```
       Apply same pattern to: `requires_org_membership`, `requires_org_role`, `requires_org_admin`, `requires_org_owner`, `requires_min_org_role`, `requires_team_membership`.
       For decorators that check membership or role, the async wrapper must use async ORM (`.afirst()`, `.aexists()`).

    3. **django_matt/multitenancy/utils.py**: Add async variants of the key utility functions:
