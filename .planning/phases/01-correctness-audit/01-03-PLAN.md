- If in `pyproject.toml`: remove from `[tool.pytest.ini_options]` env list
- If in `.env`: remove the line
- If in CI config: remove the environment variable

**Step 3 — Run the full test suite:**
```bash
uv run pytest tests/ -x -q
```

Expected: All 4143+ tests pass. The flag removal should cause zero new failures because Plans 01-01 and 01-02 already fixed all async/sync ORM violations.

**Step 4 — If any tests fail:**
For each failure:
1. Read the traceback — is it a `SynchronousOnlyOperation` error?
2. If yes: this is an unfixed async/sync violation. Fix it using the patterns from Plan 01-01 (native async ORM or sync_to_async for non-ORM sync calls).
3. If no: this is an unrelated test issue. Diagnose and fix the root cause.
4. Re-run the full suite after each fix until green.

Common failure patterns after flag removal:
- Sync fixtures called from async test context: wrap fixture ORM calls in `sync_to_async` or make the fixture async
- Sync test helper functions that do ORM work called from async tests: same approach
- `conftest.py` fixtures using `User.objects.create()` instead of `await User.objects.acreate()`: either make async or use `@pytest.fixture` (not async) with `django_db` mark
