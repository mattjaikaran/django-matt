<objective>
Audit and fix all async/sync ORM boundary violations across views, auth, multitenancy, and testing modules.

Purpose: Remove all `hasattr(queryset, 'aget')` defensive guards and `_sync_to_async()` ORM wrappers — Django 5.2+ guarantees native async ORM methods exist. Fix the magic link, session middleware, multitenancy middleware, and test client to use correct async ORM patterns. This is the largest and most critical fix in the correctness audit.
Output: All async handlers use native async ORM methods; zero defensive `hasattr` guards; zero `_sync_to_async` local wrappers for ORM calls.
</objective>

2. Convert all ORM calls that used `_sync_to_async` to native async ORM:
   - `await _sync_to_async(OAuthConnection.objects.update_or_create)(...)` -> `await OAuthConnection.objects.aupdate_or_create(...)`
   - `await _sync_to_async(list)(OAuthConnection.objects.filter(user=request.user))` -> `[conn async for conn in OAuthConnection.objects.filter(user=request.user)]`
   - `await _sync_to_async(OAuthConnection.objects.get)(...)` -> `await OAuthConnection.objects.aget(...)`
   - `await _sync_to_async(connection.delete)()` -> `await connection.adelete()`
   - `await _sync_to_async(User.objects.get)(email=...)` -> `await User.objects.aget(email=...)`
