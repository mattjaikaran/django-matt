       - `delete()` on the model sets `deleted_at` (soft delete) AND creates an audit log entry with action="delete"

    4. **audit/utils.py:** Verify `get_audit_history()`, `get_user_actions()`, `get_recent_activity()` return proper querysets. These serve AUDIT-03 (query API for admin dashboards).
