1. Update `django_matt/config/components/performance.py`:
   - Add `MATT_API_MODE` as a setting (default `False`)
   - Define `MIDDLEWARE_STRIP_LIST` constant:
     ```python
     MIDDLEWARE_STRIP_LIST = [
         "django.middleware.csrf.CsrfViewMiddleware",
         "django.contrib.sessions.middleware.SessionMiddleware",
         "django.contrib.messages.middleware.MessageMiddleware",
         "django.middleware.clickjacking.XFrameOptionsMiddleware",
     ]
     ```
   - Define `MIDDLEWARE_KEEP_LIST` constant (always active):
     ```python
     MIDDLEWARE_KEEP_LIST = [
         "django.middleware.security.SecurityMiddleware",
         "django.middleware.common.CommonMiddleware",
     ]
     ```
   - Create `apply_api_mode(middleware_list: list[str]) -> list[str]` function:
     - Iterates `middleware_list`, removes any middleware whose full dotted path matches an entry in `MIDDLEWARE_STRIP_LIST`
     - Logs stripped middleware at INFO level via `logging.getLogger("django_matt")`
     - Logs active (remaining) middleware at INFO level
     - Returns the filtered list
     - IMPORTANT: Does NOT strip middleware that is in `MIDDLEWARE_KEEP_LIST` even if someone accidentally adds it to the strip list

2. Update `django_matt/apps.py` `DjangoMattConfig.ready()`:
   - Guard with `if getattr(settings, 'MATT_API_MODE', False):`
   - Import `apply_api_mode` from `django_matt.config.components.performance`
   - Call `settings.MIDDLEWARE = apply_api_mode(list(settings.MIDDLEWARE))` — note: `settings.MIDDLEWARE` is a list, we replace it
   - CRITICAL: Only do this in `ready()`, never at module import time (per research pitfall #1 — would run during migrations, collectstatic, etc.)
   - Log a warning if `MATT_API_MODE` is True but `MIDDLEWARE` setting doesn't contain any strippable middleware
  </action>
