2. **django_matt/billing/signals.py** -- Create new file with Django signals:
   - `subscription_synced = Signal()` -- fires after any subscription create/update/cancel sync
   - `subscription_canceled = Signal()` -- fires specifically on cancellation
   - `invoice_paid = Signal()` -- fires after invoice.paid webhook
   - `webhook_received = Signal()` -- fires on any verified webhook receipt

3. **django_matt/billing/controllers.py** -- Fix two things:
   a) In `_handle_webhook()`, change `webhook_event.mark_processed()` to `await webhook_event.amark_processed()` (and same for the error path). This fixes the SynchronousOnlyOperation bug.
   b) Implement the three subscription lifecycle handlers:
      - `_handle_subscription_created`: Look up BillingCustomer by `{provider}_customer_id` field from `data.get("customer")`. Use `await Subscription.objects.aupdate_or_create(provider=provider, provider_subscription_id=data["id"], defaults={status, current_period_start/end, cancel_at_period_end via _parse_timestamp helper})`. Fire `subscription_synced` signal via `await sync_to_async(subscription_synced.send)(sender=Subscription, subscription=subscription, provider=provider, event_type="created", raw_data=data)`.
      - `_handle_subscription_updated`: Same pattern but with event_type="updated".
      - `_handle_subscription_canceled`: Same pattern but sets `status=Subscription.Status.CANCELED`, `canceled_at=timezone.now()`. Fires both `subscription_synced` and `subscription_canceled` signals.
   c) Add a `_parse_timestamp` helper at module level: accepts int (Unix epoch) or str (ISO format) or None, returns datetime or None. Use `datetime.fromtimestamp(ts, tz=timezone.utc)` for ints.
   d) Also implement `_handle_invoice_paid` with similar pattern -- look up Invoice by provider_invoice_id, update status, fire `invoice_paid` signal. If Invoice lookup fails, log warning and return (no crash).

4. **django_matt/billing/testing.py** -- Create new file with mock event factories per user decision:
   - `mock_stripe_event(event_type, data, secret)` -> `tuple[bytes, str]` (payload, signature header)
   - `mock_paypal_event(event_type, data)` -> `tuple[bytes, dict[str, str]]` (payload, headers dict)
   - `mock_polar_event(event_type, data, secret)` -> `tuple[bytes, str]` (payload, signature header)
   Each produces valid payloads matching the exact HMAC algorithm used by the real provider's `verify_webhook()`. Use `orjson.dumps()` for serialization. Stripe uses `t={timestamp},v1={hmac_sha256}` format. Polar uses `sha256={hmac_sha256}` format. PayPal returns JSON body with transmission headers.

5. **django_matt/billing/__init__.py** -- Add imports and __all__ entries for:
   - `from django_matt.billing.signals import subscription_synced, subscription_canceled, invoice_paid, webhook_received`
   - `from django_matt.billing.testing import mock_stripe_event, mock_paypal_event, mock_polar_event`
   Add to `__all__` list.
