Rust-Powered Performance

Optional PyO3 native extensions for router, JWT, serialization, and rate limiting. Pure-Python by default with up to 1.9× speedup when Rust extensions are installed. Beats FastAPI, DRF, and Django Ninja on route matching, serialization, and end-to-end throughput.

Auto-Generated Types

Generate TypeScript, Swift, and Python client types from your Pydantic schemas. Watch mode, custom templates, and full OpenAPI 3.1 spec generation. End-to-end type safety across your entire stack.

Batteries Included

JWT, OAuth (Google/GitHub/Apple/Microsoft), Passkeys/WebAuthn, SSO, Stripe/PayPal/Polar billing, WebSockets, SSE streaming, CQRS, event bus, multi-tenancy, secrets management, A/B experiments — all built in.

Async-First Architecture

Built for Python 3.12+ with native async/await throughout. Async controllers, services, event handlers, and streaming responses. Sync fallbacks where needed — you pick the paradigm.

Developer Experience

Hot reload, interactive Swagger UI, matt audit for code quality, AI context generation for Claude/Cursor, error overlays, scaffold generators, and first-class Vite, Inertia.js, and HTMX support.

Modular by Default

Package-based app structure with one model per file. Services for business logic, controllers as thin HTTP adapters. Scales from 1 model to 50 without maintenance pain. Scaffold with startapp.

Start building in seconds

One command to install, three lines to your first endpoint.

1 Install 
# pip
pip install django-matt

# uv (recommended)
uv add django-matt
2 Add to Django settings 
# settings.py
INSTALLED_APPS = [
    "django_matt",
    # ...
]
3 Create your first endpoint 
from django_matt import DjangoMattAPI
from pydantic import BaseModel

api = DjangoMattAPI(title="My API", version="1.0.0")

class HelloResponse(BaseModel):
    message: str

@api.get("/hello", response=HelloResponse)
async def hello(request):
    return {"message": "Hello, World!"}

# urls.py
from django.urls import path
from .api import api

urlpatterns = [
    path("api/", api.urls),
]
4 Run it 
python manage.py runserver
# Open http://localhost:8000/api/docs for Swagger UI
# Open http://localhost:8000/api/hello for your endpoint
