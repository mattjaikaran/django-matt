# sync_types Command

Generate TypeScript, Swift, or Zod types from Pydantic schemas and Django models.

## Synopsis

```bash
python manage.py sync_types [OPTIONS]
```

## Description

The `sync_types` command converts your Python Pydantic schemas into frontend-compatible types:

- **TypeScript** - Interfaces for React, Vue, Angular, Node.js
- **Zod** - Runtime validation schemas for TypeScript
- **Swift** - Codable structs for iOS/macOS
- **API Client** - Full typed client with all endpoints

This enables end-to-end type safety between your Django backend and frontend applications.

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `--config`, `-c` | None | Use config file (auto-discovers or specify path) |
| `--target`, `-t` | `typescript` | Target: `typescript`, `ts`, `zod`, `swift`, `api-client`, `all` |
| `--output`, `-o` | stdout | Output file path |
| `--apps`, `-a` | None | Comma-separated Django app names to scan |
| `--modules`, `-m` | None | Comma-separated Python module paths |
| `--models` | `false` | Include Django models (not just Pydantic) |
| `--watch`, `-w` | `false` | Watch for changes and regenerate |
| `--watch-interval` | `1.0` | Watch interval in seconds |
| `--watch-dirs` | Auto-detect | Directories to watch |
| `--debounce` | `0.5` | Debounce delay for watch mode |
| `--force-polling` | `false` | Force polling mode (no watchdog) |
| `--clear-screen` | `false` | Clear screen on regeneration |
| `--camel-case` | `false` | Convert field names to camelCase |
| `--base-url` | `/api` | Base URL for API client |
| `--include-react-query` | `false` | Include React Query hooks |
| `--include-swr` | `false` | Include SWR hooks |

## Examples

### TypeScript Generation

```bash
# Generate TypeScript types to stdout
python manage.py sync_types

# Generate to file
python manage.py sync_types --target typescript --output frontend/src/types/api.ts

# From specific apps
python manage.py sync_types --apps myapp,users --output types.ts

# Include Django models
python manage.py sync_types --models --output types.ts

# camelCase field names
python manage.py sync_types --camel-case --output types.ts
```

### Zod Schema Generation

```bash
# Generate Zod schemas
python manage.py sync_types --target zod --output frontend/src/schemas/api.ts
```

### Swift Generation

```bash
# Generate Swift types
python manage.py sync_types --target swift --output ios/App/API/Models.swift
```

### API Client Generation

```bash
# Basic client
python manage.py sync_types --target api-client --output frontend/src/api/client.ts

# With React Query hooks
python manage.py sync_types \
  --target api-client \
  --include-react-query \
  --output frontend/src/api/client.ts

# With SWR hooks
python manage.py sync_types \
  --target api-client \
  --include-swr \
  --base-url /api/v1 \
  --output frontend/src/api/client.ts
```

### Watch Mode

```bash
# Watch for changes
python manage.py sync_types --target typescript --output types.ts --watch

# Watch specific directories
python manage.py sync_types \
  --watch \
  --watch-dirs myapp,users \
  --output types.ts

# Clear screen on regeneration
python manage.py sync_types --watch --clear-screen --output types.ts

# Custom intervals
python manage.py sync_types \
  --watch \
  --watch-interval 2.0 \
  --debounce 1.0 \
  --output types.ts
```

### Configuration File

```bash
# Auto-discover config (django_matt_codegen.py or pyproject.toml)
python manage.py sync_types --config

# Specific config file
python manage.py sync_types --config path/to/config.py

# Config with watch mode
python manage.py sync_types --config --watch
```

### API Client Output

```typescript
// Auto-generated by django-matt sync_types

// Types (included)
export interface ProductSchema {
  id: string;
  name: string;
  // ...
}

// API Client
export interface ApiClientConfig {
  baseUrl?: string;
  headers?: Record<string, string>;
  onError?: (error: Error) => void;
}

export class ApiClient {
  private baseUrl: string;
  private headers: Record<string, string>;

  constructor(config: ApiClientConfig = {}) {
    this.baseUrl = config.baseUrl ?? "/api";
    this.headers = config.headers ?? {};
  }

  setAuthToken(token: string) {
    this.headers["Authorization"] = `Bearer ${token}`;
  }

  clearAuthToken() {
    delete this.headers["Authorization"];
  }

  async request<T>(
    method: string,
    path: string,
    options: { body?: any; params?: Record<string, any> } = {}
  ): Promise<T> {
    const url = new URL(path, this.baseUrl);

    if (options.params) {
      Object.entries(options.params).forEach(([key, value]) => {
        if (value !== undefined && value !== null) {
          url.searchParams.append(key, String(value));
        }
      });
    }

    const response = await fetch(url.toString(), {
      method,
      headers: {
        "Content-Type": "application/json",
        ...this.headers,
      },
      body: options.body ? JSON.stringify(options.body) : undefined,
    });

    if (!response.ok) {
      const error = new Error(`HTTP ${response.status}`);
      if (this.onError) this.onError(error);
      throw error;
    }

    return response.json();
  }

  async get<T>(path: string, params?: Record<string, any>): Promise<T> {
    return this.request<T>("GET", path, { params });
  }

  async post<T>(path: string, body?: any): Promise<T> {
    return this.request<T>("POST", path, { body });
  }

  async put<T>(path: string, body?: any): Promise<T> {
    return this.request<T>("PUT", path, { body });
  }

  async patch<T>(path: string, body?: any): Promise<T> {
    return this.request<T>("PATCH", path, { body });
  }

  async delete<T>(path: string): Promise<T> {
    return this.request<T>("DELETE", path);
  }
}

export const api = new ApiClient();
```

## Configuration File

Create `django_matt_codegen.py` in your project root:

```python
from django_matt.codegen.config import CodegenConfig, ModelConfig

config = CodegenConfig(
    # Target framework
    framework="typescript",  # or "zod", "swift"
    ui_library="react",

    # Output settings
    output_dir="frontend/src/types",
    camel_case=True,

    # API client settings
    base_url="/api/v1",

    # Watch settings
    watch_dirs=["myapp", "users"],
    poll_interval=1.0,
    debounce_delay=0.5,

    # Models to include
    models=[
        ModelConfig(
            path="myapp.schemas.ProductSchema",
            name="Product",
        ),
        ModelConfig(
            path="myapp.schemas.UserSchema",
            name="User",
        ),
    ],
)
```

Or use `pyproject.toml`:

```toml
[tool.django_matt.codegen]
framework = "typescript"
output_dir = "frontend/src/types"
camel_case = true
watch_dirs = ["myapp", "users"]

[[tool.django_matt.codegen.models]]
path = "myapp.schemas.ProductSchema"
name = "Product"
```

Then run:

```bash
python manage.py sync_types --config
```

## Type Mapping Reference

| Python Type | TypeScript | Zod | Swift |
|-------------|-----------|-----|-------|
| `str` | `string` | `z.string()` | `String` |
| `int` | `number` | `z.number()` | `Int` |
| `float` | `number` | `z.number()` | `Double` |
| `bool` | `boolean` | `z.boolean()` | `Bool` |
| `datetime` | `string` | `z.string().datetime()` | `Date` |
| `date` | `string` | `z.string()` | `Date` |
| `UUID` | `string` | `z.string().uuid()` | `UUID` |
| `list[T]` | `T[]` | `z.array()` | `[T]` |
| `dict` | `Record<string, any>` | `z.record()` | `[String: Any]` |
| `Optional[T]` | `T \| null` | `.nullable()` | `T?` |

## Best Practices

!!! tip "Watch Mode for Development"
    Use watch mode during development:
    ```bash
    python manage.py sync_types --watch --output frontend/types/api.ts
    ```

!!! tip "camelCase for JavaScript"
    Use `--camel-case` for JavaScript/TypeScript conventions:
    ```bash
    python manage.py sync_types --camel-case
    ```

!!! tip "CI/CD Integration"
    Add to your CI pipeline:
    ```yaml
    - name: Generate Types
      run: python manage.py sync_types --output frontend/types/api.ts

    - name: Verify Types
      run: cd frontend && npm run typecheck
    ```

!!! warning "Don't Edit Generated Files"
    Generated files should not be manually edited. Add to `.prettierignore`:
    ```
    frontend/src/types/api.ts
    ```
