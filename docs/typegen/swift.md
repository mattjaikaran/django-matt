# Swift Generation

Generate Swift `Codable` structs from Pydantic schemas and Django models for use in
iOS / macOS applications.

## Quick Start

```bash
python manage.py sync_types --target swift --output ios/Generated/Models.swift --apps myapp
```

## Generated Output

Input:

```python
# myapp/schemas.py
from pydantic import BaseModel
from datetime import datetime
from uuid import UUID

class ProductSchema(BaseModel):
    id: UUID
    name: str
    description: str | None = None
    price: float
    is_active: bool = True
    created_at: datetime
```

Generated Swift:

```swift
// Auto-generated by django-matt sync_types
// Do not edit manually

import Foundation

struct ProductSchema: Codable {
    let id: UUID
    let name: String
    let description: String?
    let price: Double
    let isActive: Bool
    let createdAt: Date

    enum CodingKeys: String, CodingKey {
        case id
        case name
        case description
        case price
        case isActive = "is_active"
        case createdAt = "created_at"
    }
}
```

Snake\_case fields are automatically converted to camelCase in the Swift struct, and a
`CodingKeys` enum is generated to map back to the server's snake\_case JSON keys.

## Type Mapping

| Python / Pydantic type | Swift |
|------------------------|-------|
| `str` | `String` |
| `int` | `Int` |
| `float` | `Double` |
| `bool` | `Bool` |
| `datetime.datetime` | `Date` |
| `datetime.date` | `Date` |
| `uuid.UUID` | `UUID` |
| `Optional[T]` / `T \| None` | `T?` |
| `list[T]` | `[T]` |
| `dict[str, V]` | `[String: V]` |

## Configuration via Settings

```python
# settings.py
DJANGO_MATT = {
    "TYPEGEN": {
        "SWIFT_OUTPUT_DIR": "ios/Generated",
    },
}
```
