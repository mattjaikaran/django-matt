    Type Generation Commands¶

    Generate TypeScript, Swift, and Zod types from your Pydantic schemas for type-safe frontend development.

    Overview¶

    Django Matt can automatically generate frontend types from your Python schemas:

    Target Output Use Case
    TypeScript .ts interfaces React, Vue, Angular, Node.js
    Zod .ts Zod schemas Runtime validation in TypeScript
    Swift .swift Codable structs iOS/macOS apps
    API Client .ts typed client Full-stack type safety

    matt types ts¶

    Generate TypeScript interfaces from Pydantic schemas.

    matt types ts [OPTIONS]

    Options¶

    Option Default Description
    --output, -o stdout Output file path
    --apps, -a All apps Comma-separated app names
    --modules, -m Auto-detect Comma-separated module paths
    --models false Include Django models
    --camel-case false Convert to camelCase

    Examples¶

    # Generate to stdout
matt types ts

# Output to file
matt types ts --output frontend/src/types/api.ts

# Specific apps
matt types ts --apps myapp,users --output types.ts

# Include Django models
matt types ts --models --output types.ts

# camelCase field names
matt types ts --camel-case --output types.ts

    Generated Output¶

    Given this Pydantic schema:

    # myapp/schemas.py
from pydantic import BaseModel
from datetime import datetime
from typing import Optional

class UserSchema(BaseModel):
    id: int
    email: str
    full_name: str
    created_at: datetime
    is_active: bool = True

    TypeScript output:

    // Auto-generated by django-matt sync_types
// Do not edit manually

export interface UserSchema {
  id: number;
  email: string;
  full_name: string;
  created_at: string;  // ISO datetime
  is_active: boolean;
}

    With --camel-case:

    export interface UserSchema {
  id: number;
  email: string;
  fullName: string;
  createdAt: string;
  isActive: boolean;
}

    matt types zod¶

    Generate Zod schemas for runtime validation in TypeScript.

    matt types zod [OPTIONS]

    Options¶

    Option Default Description
    --output, -o stdout Output file path
    --apps, -a All apps Comma-separated app names
    --modules, -m Auto-detect Comma-separated module paths
    --camel-case false Convert to camelCase

    Examples¶

    # Generate Zod schemas
matt types zod --output frontend/src/schemas/api.ts

    Generated Output¶

    // Auto-generated by django-matt sync_types
import { z } from 'zod';

export const UserSchema = z.object({
  id: z.number(),
  email: z.string().email(),
  full_name: z.string(),
  created_at: z.string().datetime(),
  is_active: z.boolean().default(true),
});

export type User = z.infer<typeof UserSchema>;

    matt types swift¶

    Generate Swift Codable structs for iOS/macOS apps.

    matt types swift [OPTIONS]

    Options¶

    Option Default Description
    --output, -o stdout Output file path
    --apps, -a All apps Comma-separated app names
    --modules, -m Auto-detect Comma-separated module paths

    Examples¶

    # Generate Swift types
matt types swift --output ios/App/API/Models.swift

    Generated Output¶

    // Auto-generated by django-matt sync_types
// Do not edit manually

import Foundation

struct UserSchema: Codable {
    let id: Int
    let email: String
    let fullName: String
    let createdAt: Date
    let isActive: Bool

    enum CodingKeys: String, CodingKey {
        case id
        case email
        case fullName = "full_name"
        case createdAt = "created_at"
        case isActive = "is_active"
    }
}

    matt types client¶

    Generate a typed API client with all endpoints.

    matt types client [OPTIONS]

    Options¶

    Option Default Description
    --output, -o stdout Output file path
    --apps, -a All apps Comma-separated app names
    --base-url /api API base URL
    --react-query false Include React Query hooks
    --swr false Include SWR hooks
    --camel-case false Convert to camelCase

    Examples¶

    # Basic API client
matt types client --output frontend/src/api/client.ts

# With React Query hooks
matt types client --react-query --output frontend/src/api/client.ts

# With SWR hooks
matt types client --swr --output frontend/src/api/client.ts

# Custom base URL
matt types client --base-url /api/v1 --output client.ts

    Generated Output¶

    matt types watch¶

    Watch for schema changes and automatically regenerate types.

    matt types watch [OPTIONS]

    Options¶

    Option Default Description
    --target, -t typescript Target: typescript, zod, swift
    --output, -o stdout Output file path
    --apps, -a All apps Comma-separated app names
    --modules, -m Auto-detect Comma-separated module paths
    --watch-dirs Auto-detect Directories to watch
    --interval 1.0 Watch interval in seconds
    --clear false Clear screen on regeneration

    Examples¶

    # Watch TypeScript types
matt types watch --output frontend/src/types/api.ts

# Watch Zod schemas
matt types watch --target zod --output frontend/src/schemas.ts

# Watch specific directories
matt types watch --watch-dirs myapp,users --output types.ts

# Clear screen on change
matt types watch --clear --output types.ts

    matt types config¶

    Generate type configuration from project analysis.

    matt types config

    This creates a django_matt_codegen.py configuration file:

    # django_matt_codegen.py
from django_matt.codegen.config import CodegenConfig, ModelConfig

config = CodegenConfig(
    framework="typescript",
    ui_library="react",
    output_dir="frontend/src/types",
    camel_case=True,
    models=[
        ModelConfig(
            path="myapp.schemas.UserSchema",
            name="User",
        ),
        ModelConfig(
            path="myapp.schemas.ProductSchema",
            name="Product",
        ),
    ],
)

    Then use with:

    matt types ts --config

    Integration Examples¶

    React + TypeScript¶

    # Generate types
matt types ts --output frontend/src/types/api.ts

# Generate Zod for form validation
matt types zod --output frontend/src/schemas/api.ts

# Generate API client with React Query
matt types client --react-query --output frontend/src/api/client.ts

    Usage in React:

    import { api } from './api/client';
import { UserSchema } from './schemas/api';

// Type-safe API call
const users = await api.getUsers({ page: 1 });

// Runtime validation
const validatedUser = UserSchema.parse(userData);

    iOS/Swift¶

    # Generate Swift types
matt types swift --output ios/App/API/Models.swift

    Usage in Swift:

    let decoder = JSONDecoder()
decoder.dateDecodingStrategy = .iso8601
decoder.keyDecodingStrategy = .convertFromSnakeCase

let user = try decoder.decode(UserSchema.self, from: data)

    Monorepo Setup¶

    # In package.json scripts
{
  "scripts": {
    "types:generate": "cd backend && matt types ts --output ../frontend/src/types/api.ts",
    "types:watch": "cd backend && matt types watch --output ../frontend/src/types/api.ts"
  }
}

    Best Practices¶

    Watch Mode in Development

    Use watch mode during development for instant type updates: 

    matt types watch --output frontend/src/types/api.ts

    CI/CD Integration

    Add type generation to your CI pipeline: 

    - name: Generate Types
  run: matt types ts --output frontend/src/types/api.ts

- name: Check Types
  run: cd frontend && npm run typecheck

    Consistent Naming

    Use --camel-case for JavaScript/TypeScript conventions: 

    matt types ts --camel-case

    Regeneration

    Generated files should not be manually edited. Add a header comment: 

    // AUTO-GENERATED - DO NOT EDIT
// Run 'matt types ts' to regenerate
